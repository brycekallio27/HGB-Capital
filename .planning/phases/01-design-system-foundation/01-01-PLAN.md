```toml
[theme]
base = "dark"
primaryColor = "#C5A059"
backgroundColor = "#0A0A0A"
secondaryBackgroundColor = "#111111"
textColor = "#F5F5F5"
font = "Inter:https://fonts.googleapis.com/css2?family=Inter:ital,opsz,wght@0,14..32,100..900;1,14..32,100..900&display=swap, sans-serif"
```

Rationale for each field:
- `base = "dark"` — sets Streamlit's built-in dark theme as baseline, preventing any white flash before CSS injection fires
- `primaryColor = "#C5A059"` — brand gold applied to sliders, checkboxes, radio buttons, and active widget highlights via config (no CSS needed)
- `backgroundColor = "#0A0A0A"` — deep black app background via config (CSS injection will reinforce this with !important)
- `secondaryBackgroundColor = "#111111"` — sidebar and card surface color
- `textColor = "#F5F5F5"` — near-white text for dark surfaces
- `font` — official Google Fonts loading format introduced in Streamlit v1.44; the `"FontName:URL"` format instructs Streamlit to fetch the stylesheet and apply the font globally including to dataframe column headers, widget labels, tooltips, and all text elements. The `, sans-serif` fallback at the end of the URL string ensures graceful degradation if Google Fonts is unavailable.

Do NOT add any other sections to this file. Do NOT modify `secrets.toml`.

```python
# --- DESIGN SYSTEM: CSS Constants & Injection ---

DARK_CSS = """
<style>
/* Global app background */
.stApp,
[data-testid="stAppViewContainer"] {
    background-color: #0A0A0A !important;
    color: #F5F5F5;
}

/* Sidebar surface */
[data-testid="stSidebar"] {
    background-color: #111111 !important;
}

/* Metric values — tabular numerals + gold accent */
[data-testid="stMetricValue"] {
    font-variant-numeric: lining-nums tabular-nums;
    font-feature-settings: "lnum" 1, "tnum" 1;
    color: #F5F5F5;
}

/* Metric delta — tabular numerals */
[data-testid="stMetricDelta"] {
    font-variant-numeric: lining-nums tabular-nums;
    font-feature-settings: "lnum" 1, "tnum" 1;
}

/* DataFrames outer wrapper — tabular numerals (may not penetrate canvas; see Phase 3) */
[data-testid="stDataFrame"] {
    font-variant-numeric: lining-nums tabular-nums;
    font-feature-settings: "lnum" 1, "tnum" 1;
}

/* Semantic P&L colors — DSYS-05 (applied in 01-03-PLAN) */
.pl-positive { color: #16A34A !important; }
.pl-negative { color: #DC2626 !important; }

/* Gold accent on interactive elements */
.stButton > button {
    border-color: #C5A059;
    color: #C5A059;
}
</style>
"""

LIGHT_CSS = """
<style>
/* Global app background */
.stApp,
[data-testid="stAppViewContainer"] {
    background-color: #FAFAFA !important;
    color: #1A1A1A;
}

/* Sidebar surface */
[data-testid="stSidebar"] {
    background-color: #FFFFFF !important;
}

/* Metric values — tabular numerals */
[data-testid="stMetricValue"] {
    font-variant-numeric: lining-nums tabular-nums;
    font-feature-settings: "lnum" 1, "tnum" 1;
    color: #1A1A1A;
}

/* Metric delta — tabular numerals */
[data-testid="stMetricDelta"] {
    font-variant-numeric: lining-nums tabular-nums;
    font-feature-settings: "lnum" 1, "tnum" 1;
}

/* DataFrames outer wrapper — tabular numerals (may not penetrate canvas; see Phase 3) */
[data-testid="stDataFrame"] {
    font-variant-numeric: lining-nums tabular-nums;
    font-feature-settings: "lnum" 1, "tnum" 1;
}

/* Semantic P&L colors — DSYS-05 (applied in 01-03-PLAN) */
.pl-positive { color: #16A34A !important; }
.pl-negative { color: #DC2626 !important; }

/* Gold accent on interactive elements */
.stButton > button {
    border-color: #C5A059;
    color: #C5A059;
}
</style>
"""


def inject_css(is_dark: bool) -> None:
    """Inject the appropriate CSS block based on current theme mode."""
    st.markdown(DARK_CSS if is_dark else LIGHT_CSS, unsafe_allow_html=True)


# Initialize theme session state (dark is brand default)
if "dark_mode" not in st.session_state:
    st.session_state.dark_mode = True

# Inject CSS immediately — must happen before any UI element renders
inject_css(st.session_state.dark_mode)
```

Semantic color note: `.pl-positive` (#16A34A green) and `.pl-negative` (#DC2626 red) are defined here as CSS classes but will be wired to metric delta values in plan 01-03. Defining them here keeps the CSS canonical and centralized.
