  <name>Task 2: Add semantic delta color overrides for P&L metric to DARK_CSS and LIGHT_CSS</name>
  <files>app.py</files>
  <action>
The `c2.metric("Unrealized P&L", ...)` call in app.py uses Streamlit's built-in delta coloring. Streamlit renders positive deltas with a green arrow and negative with a red arrow using its own color values. DSYS-05 requires our specific fintech semantic colors (#16A34A green, #DC2626 red) for consistency and WCAG compliance.

Streamlit 1.50 renders metric delta elements using `[data-testid="stMetricDelta"]`. Positive and negative delta values are distinguished by an inner `<svg>` element with an up or down arrow, and the text color is applied to the wrapper. The reliable CSS override targets the delta wrapper and uses color for both the arrow SVG fill and the text color.

Add the following CSS block to the end of the `<style>` content inside DARK_CSS (before the closing `</style>` tag):

```css
/* Semantic P&L delta colors — DSYS-05 */
/* Positive delta: semantic green */
[data-testid="stMetricDelta"][aria-label*="increased"],
[data-testid="stMetricDelta"] svg[class*="up"],
.stMetricDelta--up {
    color: #16A34A !important;
    fill: #16A34A !important;
}
/* Negative delta: semantic red */
[data-testid="stMetricDelta"][aria-label*="decreased"],
[data-testid="stMetricDelta"] svg[class*="down"],
.stMetricDelta--down {
    color: #DC2626 !important;
    fill: #DC2626 !important;
}
/* Fallback: target the delta container directly via Streamlit's arrow classes */
[data-testid="stMetricDelta"] > div {
    font-variant-numeric: lining-nums tabular-nums;
}
```

Add the IDENTICAL CSS block to the end of the `<style>` content inside LIGHT_CSS (before the closing `</style>` tag). The semantic colors (#16A34A and #DC2626) are the same for both modes — they are designed for WCAG AA contrast on both #0A0A0A and #FAFAFA backgrounds.

Implementation note: Streamlit's metric delta DOM structure is not fully documented, so a multi-selector approach is used to maximize CSS hit rate:
- `[aria-label*="increased/decreased"]` — targets the ARIA-annotated delta wrapper (high confidence in Streamlit 1.44+)
- `svg[class*="up/down"]` — targets the arrow SVG inside the delta (fallback for versions that use class-based SVG styling)
- `.stMetricDelta--up/down` — targets any BEM-style class Streamlit may apply (forward-compat guard)
- `fill` is included for SVG elements (color alone does not recolor SVG paths)

After the insertion verify with DevTools in browser, as documented in the checkpoint in plan 01-02. If none of the selectors match (delta remains default green/red), document in SUMMARY.md as a verification item for Phase 3 (PORT-03 handles metric widget deep styling).

Note: The `.pl-positive` and `.pl-negative` CSS classes added in plan 01-01 are helper classes for future use in custom HTML elements. The selectors in this task are what actually target Streamlit's native metric delta DOM.
